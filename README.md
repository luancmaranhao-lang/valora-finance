# React + Vite

This template provides a minimal setup to get React working in Vite with HMR and some ESLint rules.

Currently, two official plugins are available:

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react) uses [Oxc](https://oxc.rs)
- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react-swc) uses [SWC](https://swc.rs/)

## React Compiler

The React Compiler is not enabled on this template because of its impact on dev & build performances. To add it, see [this documentation](https://react.dev/learn/react-compiler/installation).

## Expanding the ESLint configuration

If you are developing a production application, we recommend using TypeScript with type-aware lint rules enabled. Check out the [TS template](https://github.com/vitejs/vite/tree/main/packages/create-vite/template-react-ts) for information on how to integrate TypeScript and [`typescript-eslint`](https://typescript-eslint.io) in your project.

# 💰 Valora Finance

Sistema de controle financeiro pessoal com foco em organização, visão clara e tomada de decisão inteligente.

---

## 🎯 Objetivo

Permitir ao usuário:

- controlar entradas e saídas
- visualizar saldo real
- entender para onde o dinheiro vai
- tomar decisões financeiras melhores

---

## ⚙️ Funcionalidades

- cadastro de contas
- lançamentos financeiros
- categorização de gastos
- dashboard visual

---

## 🤖 Inteligência Artificial (Diferencial)

O Valora utiliza IA para transformar dados financeiros em decisões inteligentes:

- análise automática de padrões de gastos
- identificação de desperdícios
- sugestões de economia personalizadas
- alertas de comportamento financeiro de risco
- recomendações baseadas no histórico do usuário

A IA atua como um **mentor financeiro digital**, ajudando o usuário a evoluir sua vida financeira de forma contínua.

---

## 🚀 Visão futura

- IA preditiva (prever saldo futuro)
- metas financeiras inteligentes
- controle de cartões com análise automática
- grupos familiares com divisão de despesas
- assistente financeiro conversacional

---

## 🧱 Estrutura

- `src` → aplicação
- `components` → componentes reutilizáveis
- `pages` → telas
- `services` → integração com API/Supabase

---

## 🧠 Regras

- saldo = entradas - saídas
- cada lançamento pertence a uma conta
- categorias definem análise
- a IA aprende com o comportamento do usuário
